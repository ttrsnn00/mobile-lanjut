# shiroine

sebuah aplikasi mobile e-commerce tanaman hias yang dibangun dengan **Flutter** dan terintegrasi dengan API **Laravel-Sanctum**.

untuk repo **Laravel-Sanctum**
https://github.com/ttrsnn00/api-mobile-laravel

## Fitur Utama
- **Autentikasi User:** Login & Registrasi berbasis token (Laravel Sanctum).
- **Katalog Tanaman:** Daftar produk tanaman beserta informasi detail.
- **Keranjang Belanja (Cart):** Tambah, ubah jumlah, dan kelola item belanjaan secara reaktif.
- **Checkout & Riwayat Pesanan:** Proses pemesanan hingga halaman konfirmasi sukses dan riwayat transaksi.

## Tech Stack
- **Frontend Mobile:** Flutter, GetX (State Management & Routing), GetStorage, HTTP
- **Backend API:** Laravel, Laravel Sanctum, MySQL
